StageKontrol Bridge — Windows
=============================

Le bridge relie l'app StageKontrol (téléphone) à votre logiciel musical (Kontakt, Reaper…).

1. Installez loopMIDI (gratuit) : https://www.tobias-erichsen.de/software/loopmidi.html
   Ouvrez-le et créez un port nommé exactement : stageKontrol
2. Double-cliquez sur StageKontrol-Bridge.exe (dans le dossier StageKontrol-Bridge).
   Si Windows demande l'autorisation du pare-feu, acceptez pour les réseaux privés.
   Si Windows SmartScreen affiche « Windows a protégé votre ordinateur » :
   « Informations complémentaires » → « Exécuter quand même ».
3. Dans votre logiciel, choisissez l'entrée MIDI « stageKontrol ».
4. Dans l'app : Réglages → « Bridges trouvés sur le réseau » → Utiliser.
   Ou par câble USB : choisissez « MIDI » dans la notification USB du téléphone.

Laissez la fenêtre du bridge ouverte pendant que vous jouez (Ctrl+C pour l'arrêter).
Clavier maître branché sur le PC : désactivez-le comme entrée MIDI directe dans votre logiciel.
