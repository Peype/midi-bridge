StageKontrol Bridge — Windows
=============================

Le bridge relie l'app StageKontrol (téléphone) à votre logiciel musical (Kontakt, Reaper…).

1. Double-cliquez sur StageKontrol-Bridge.exe (dans le dossier StageKontrol-Bridge).
   Une page s'ouvre dans votre navigateur : elle vous guide pour la suite.
   Si Windows SmartScreen affiche « Windows a protégé votre ordinateur » :
   « Informations complémentaires » → « Exécuter quand même ».
   Si Windows demande l'autorisation du pare-feu, acceptez pour les réseaux privés.
2. Une seule fois : installez loopMIDI (gratuit), ouvrez-le et créez un port nommé
   exactement « stageKontrol » (la page montre comment). Le bridge le prend aussitôt,
   sans redémarrer. Dans loopMIDI, activez le démarrage avec Windows.
3. Scannez le QR code de la page avec l'appareil photo du téléphone : l'app se connecte.
   (Même Wi-Fi pour le téléphone et le PC ; ou câble USB, puis « MIDI » sur le téléphone.)
4. Dans votre logiciel, choisissez l'entrée MIDI « stageKontrol ».

Laissez la fenêtre du bridge ouverte pendant que vous jouez ; fermez-la pour l'arrêter.
Page d'état à tout moment : http://localhost:8765/
Clavier maître branché sur le PC : désactivez-le comme entrée MIDI directe dans votre logiciel.
